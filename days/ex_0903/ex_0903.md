 ## 3\. Python 기본 문법 공부

 ### ✔️ 자료구조 종류

 자료구조는 **여러 개의 데이터를 하나의 변수에 저장하는 방법**

 | 자료구조 | 설명 |
| --- | --- |
| `list` | 여러 값을 순서대로 저장하고 수정할 수 있음 |
| `tuple` | 여러 값을 순서대로 저장하고 수정할 수 없음 |
| `set` | 중복된 값을 저장하지 않음 |
| `dict` | 키와 값의 쌍으로 데이터를 저장 |

 #### Example

```
# 리스트
fruits = ["사과", "바나나", "포도"]

# 튜플
colors = ("빨강", "파랑", "초록")

# 세트
numbers = {1, 2, 2, 3}

# 딕셔너리
user = {
    "name": "홍길동",
    "age": 30
}

print(fruits)
print(colors)
print(numbers)
print(user)
```

 #### 결과

```
['사과', '바나나', '포도']
('빨강', '파랑', '초록')
{1, 2, 3}
{'name': '홍길동', 'age': 30}
```

 > `set`은 중복된 값을 자동으로 제거

 ### ✔️ 인덱싱 · 슬라이싱 사용 방법

 **인덱싱**은 특정 위치의 값을, **슬라이싱**은 원하는 범위의 값을 가져옴

```
fruits = ["사과", "바나나", "포도", "딸기", "수박"]

# 인덱스는 0부터 시작
print(fruits[0])
print(fruits[1])

# 음수 인덱스
print(fruits[-1])
print(fruits[-2])

# 슬라이싱 [시작:끝]
print(fruits[1:3])

# 처음부터 3번 인덱스 전까지
print(fruits[:3])

# 2번 인덱스부터 마지막까지
print(fruits[2:])
```

 #### 결과

```
사과
바나나
수박
딸기
['바나나', '포도']
['사과', '바나나', '포도']
['포도', '딸기', '수박']
```

 > 인덱스는 **0부터 시작**
>
>  슬라이싱에서는 **끝 번호의 값은 포함되지 않음**

 ### ✔️ 리스트 사용 방법

 리스트는 여러 개의 값을 저장할 수 있으며, 값을 **추가, 수정, 삭제, 정렬**할 수 있음.

 #### Example

```
fruits = ["사과", "바나나", "포도"]

# 마지막에 값 추가
fruits.append("딸기")

# 원하는 위치에 값 추가
fruits.insert(1, "수박")

# 값 수정
fruits[0] = "복숭아"

# 특정 값 삭제
fruits.remove("포도")

# 마지막 값 삭제
fruits.pop()

# 정렬
fruits.sort()

# 순서 뒤집기
fruits.reverse()

# 리스트 길이 확인
print(len(fruits))

print(fruits)
```

 #### 주요 기능

 | 메서드 | 설명 |
| --- | --- |
| `append()` | 마지막에 값 추가 |
| `insert()` | 원하는 위치에 값 추가 |
| `remove()` | 특정 값 삭제 |
| `pop()` | 특정 위치의 값 삭제 |
| `sort()` | 값을 정렬 |
| `reverse()` | 리스트 순서를 뒤집음 |
| `len()` | 리스트의 길이를 확인 |

 #### 결과

```
3
['수박', '복숭아', '바나나']
```

 ### ✔️ 딕셔너리 사용 방법

 딕셔너리는 **키와 값**을 한 쌍으로 저장

```
# 딕셔너리 생성
user = {
    "name": "홍길동",
    "age": 30,
    "city": "서울"
}

# 키를 이용해 값 가져오기
print(user["name"])

# 값 수정
user["age"] = 31

# 새로운 키와 값 추가
user["job"] = "개발자"

# 키와 값 삭제
del user["city"]

print(user)
```

 #### 결과

```
홍길동
{'name': '홍길동', 'age': 31, 'job': '개발자'}
```

 #### 자주 사용하는 방법

```
user["name"]        # 값 가져오기
user["age"] = 31    # 값 수정
user["job"] = "개발자"  # 값 추가

del user["city"]    # 값 삭제
```

 ### ✔️ 함수 정의 방법

 함수는 **특정 작업을 하나로 묶어 필요할 때 사용**

 `def`를 사용하여 함수를 생성하고, 결과를 돌려줄 때는 `return` 사용

 #### Example

```
# 함수 만들기
def hello(name):
    return "안녕하세요, " + name

# 함수 사용하기
result = hello("홍길동")

print(result)
```

 #### 결과

```
안녕하세요, 홍길동
```

 ### ✔️ 예외처리 사용 방법
 `try`와 `except`를 사용하면 오류가 발생했을 때 프로그램이 갑자기 종료되지 않도록 처리할 수 있음.

 | 문법 | 설명 |
| --- | --- |
| `try` | 오류가 발생할 수 있는 코드 |
| `except` | 오류가 발생했을 때 실행 |
| `finally` | 오류가 발생해도 마지막에 항상 실행 |

 #### Example

```
try:
    number = int("안녕하세요")
    print(number)

except ValueError:
    print("숫자로 변환할 수 없습니다.")

finally:
    print("실행 완료")
```

 #### 결과

```
숫자로 변환할 수 없습니다.
실행 완료
```

 > `"안녕하세요"`는 숫자로 변환할 수 없기 때문에 `ValueError`가 발생한다.
>
>  `except`에서 오류를 처리하고, `finally`는 마지막에 실행된다.

 ## ✔️ 종합 실습
```
def create_user(name, age):
    return {
        "name": name,
        "age": age
    }

users = [
    create_user("홍길동", 30),
    create_user("김철수", 25),
    create_user("이영희", 28)
]

for user in users:
    print(user)
```

 #### 결과

```
{'name': '홍길동', 'age': 30}
{'name': '김철수', 'age': 25}
{'name': '이영희', 'age': 28}
```

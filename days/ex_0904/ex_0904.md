 ## 2\. GitHub

 Git과 GitHub를 이용하여 **코드를 관리하고 변경 내용을 기록**할 수 있음.

 ### ✔️ Git · GitHub · GitHub Desktop

 | 이름 | 설명 |
| --- | --- |
| **Git** | 코드의 변경 내용을 기록하고 관리하는 프로그램 |
| **GitHub** | Git으로 관리하는 코드를 온라인에 저장하는 서비스 |
| **GitHub Desktop** | Git을 화면에서 쉽게 사용할 수 있도록 도와주는 프로그램 |

---

2. **Repository(저장소) 생성**
   - GitHub에서 새로운 저장소 생성
   - 저장소 이름 및 공개 여부 설정
3. **GitHub Desktop에서 저장소 선택**
   - 생성한 저장소 선택

---

 ### ✔️ Commit · Push

 Git을 사용하면 작업 내용을 기록하고 GitHub에 올릴 수 있음

 - **Commit** : 변경된 작업 내용을 기록
- **Push** : Commit한 내용을 GitHub에 업로드

```
프로젝트 수정
    ↓
변경 사항 확인
    ↓
  Commit
    ↓
변경 내용 기록
    ↓
   Push
    ↓
GitHub에 업로드
    ↓
GitHub에서 확인
```

 ## 3\. Python 기본 문법


 ### ✔️ f-string 사용 방법

 f-string은 **문자열 안에 변수의 값을 쉽게 넣을 수 있는 방법**
```
age = 36

txt = f"age : {age}"
print(txt)

txt2 = f"age : {age:.2f}"
print(txt2)
```

 ### 결과

```
age : 36
age : 36.00
```

 > `:.2f`는 소수점 아래를 **2자리까지 표시**

---

 ### ✔️ 문자열 메서드 사용 방법

 #### `center()`

 문자열을 가운데에 배치

```
txt = "banana"

print(txt.center(20))
```

 #### `find()`

 문자열 안에서 특정 문자가 시작하는 위치를 찾음

```
txt = "Hello, welcome to my world."

print(txt.find("welcome"))
```

 #### `isupper()`

 문자열이 모두 대문자인지 확인

```
txt = "THIS IS NOW!"

print(txt.isupper())
```

 #### `lstrip()`

 문자열 왼쪽의 공백을 제거

```
txt = "     banana     "

x = txt.lstrip()

print("of all fruits", x, "is my favorite")
```

 #### `translate()`

 문자열의 특정 문자를 다른 문자로 변경

```
txt = "Hello Sam!"

mytable = str.maketrans("S", "P")

print(txt.translate(mytable))
```

 ### 결과

```
             banana
7
True
of all fruits banana      is my favorite
Hello Pam!
```

---

 ### ✔️ 딕셔너리 메서드 사용 방법

 딕셔너리에서 키와 값을 확인할 때 여러 메서드를 사용할 수 있음

 #### `keys()`

 딕셔너리에 있는 **키**를 확인

```
car = {
    "brand": "Ford",
    "model": "Mustang",
    "year": 1964
}

x = car.keys()

print(x)
```

 #### 새로운 값 추가

```
car["color"] = "white"

print(x)
```

 #### `values()`

 딕셔너리에 있는 **값**을 확인

```
y = car.values()

print(y)
```

 ### 전체 코드

```
car = {
    "brand": "Ford",
    "model": "Mustang",
    "year": 1964
}

# 딕셔너리의 키 확인
x = car.keys()
print(x)

# 새로운 키와 값 추가
car["color"] = "white"
print(x)

# 딕셔너리의 값 확인
y = car.values()
print(y)

print(car)
```

 ### 결과

```
dict_keys(['brand', 'model', 'year'])
dict_keys(['brand', 'model', 'year', 'color'])
dict_values(['Ford', 'Mustang', 1964, 'white'])
{'brand': 'Ford', 'model': 'Mustang', 'year': 1964, 'color': 'white'}
```

 ## 4\. NumPy

 NumPy는 Python에서 **숫자와 배열을 쉽게 다루기 위한 라이브러리**

 ### NumPy 설치

```
pip install numpy
```

 ### ✔️ NumPy 배열 생성 방법

 NumPy를 사용하려면 먼저 `numpy`를 import 한다.

```
import numpy as np

arr = np.array([1, 2, 3])

print(arr)
print(type(arr))
```

 ### 결과

```
[1 2 3]
<class 'numpy.ndarray'>
```

 > `np.array()`를 사용하면 NumPy 배열을 만들 수 있음.

---

 ### ✔️ 배열의 차원

 배열은 데이터가 몇 겹으로 구성되어 있는지에 따라 차원이 달라짐

 #### 0차원

 하나의 값만 가지고 있는 배열

```
arr0 = np.array(100)
```

```
100
```

 #### 1차원

 값이 한 줄로 나열되어 있음

```
arr1 = np.array([1, 2, 3])
```

```
[1 2 3]
```

 #### 2차원

 행과 열로 구성되어 있음

```
arr2 = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
```

```
[[1 2 3]
 [4 5 6]]
```

 #### 3차원

 2차원 배열이 여러 개 모여 있는 형태

```
arr3 = np.array([
    [
        [1, 2, 3],
        [4, 5, 6]
    ],
    [
        [1, 2, 3],
        [4, 5, 6]
    ]
])
```

---

 ### ✔️ `ndim` 사용 방법

 `ndim`을 사용하면 **배열이 몇 차원인지 확인**할 수 있음.

```
print(arr1.ndim)
print(arr2.ndim)
print(arr3.ndim)
```

 ### 결과

```
1
2
3
```

---

 ### ✔️ `ndmin` 사용 방법

 `ndmin`을 사용하면 **배열의 최소 차원 수를 지정**할 수 있음

```
import numpy as np

arr5 = np.array([1, 2, 3, 4], ndmin=5)

print(arr5)
print(arr5.ndim)
```

 ### 결과

```
[[[[[1 2 3 4]]]]]
5
```

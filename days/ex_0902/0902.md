### ✔️ 변수 사용 방법
변수는 **값을 저장하는 공간**
```
name = "홍길동"
age = 30
height = 175.5

print(name)
print(age + 1)
```
> 변수 이름은 영문자, 숫자, 밑줄(`_`)을 사용할 수 지만 숫자로 시작할 수 없음.
---

### ✔️ 출력 방법
```
name = "홍길동"
age = 30

print(name)
print(age)

print(name, age, sep=',')
```

#### 실행 결과

```
홍길동
30
홍길동,30
```

 > `sep=','`를 사용하면 여러 값을 `,`로 구분해서 출력할 수 있음

 ## ✔️ 연산자 정리

 ### 산술 연산자

 숫자를 계산할 때 사용하는 연산자.

 | 연산자 | 의미 |
| --- | --- |
| `+` | 더하기 |
| `-` | 빼기 |
| `*` | 곱하기 |
| `/` | 나누기 |
| `%` | 나머지 |
| `**` | 거듭제곱 |
| `//` | 몫 |

 #### Example

```
a = 10
b = 5

print(a + b)   # 15
print(a - b)   # 5
print(a * b)   # 50
print(a / b)   # 2.0
print(a % b)   # 0
print(a ** b)  # 100000
print(a // b)  # 2
```

---

 ### 비교 연산자

 두 값을 비교할 때 사용하는 연산자 (`True` 또는 `False`)

 | 연산자 | 의미 |
| --- | --- |
| `==` | 같다 |
| `!=` | 다르다 |
| `>` | 크다 |
| `<` | 작다 |
| `>=` | 크거나 같다 |
| `<=` | 작거나 같다 |

 #### Example

```
a = 10
b = 5

print(a == b)  # False
print(a != b)  # True
print(a > b)   # True
print(a < b)   # False
print(a >= b)  # True
print(a <= b)  # False
```

---

 ### 논리 연산자

 여러 조건을 함께 사용할 때 사용하는 연산자

 | 연산자 | 의미 |
| --- | --- |
| `and` | 그리고 |
| `or` | 또는 |
| `not` | 반대로 |

 #### Example

```
a = 10
b = 5

# 두 조건이 모두 맞아야 True
print(a > 5 and b < 10)  # True

# 하나만 맞아도 True
print(a > 15 or b < 10)  # True

# 결과를 반대로 변경
print(not a < 5)  # True
```

---

 ### 대입 연산자

 변수에 값을 넣거나 계산한 값을 다시 저장할 때 사용

 | 연산자 | 의미 |
| --- | --- |
| `=` | 값 저장 |
| `+=` | 더한 후 저장 |
| `-=` | 뺀 후 저장 |
| `*=` | 곱한 후 저장 |
| `/=` | 나눈 후 저장 |

 #### Example

```
a = 10
b = 5

a += b
print(a)  # 15

a -= b
print(a)  # 10

a *= b
print(a)  # 50

a /= b
print(a)  # 10.0
```
---

 ### 포함 연산자

 특정 값이 데이터 안에 있는지 확인할 때 사용

 | 연산자 | 의미 |
| --- | --- |
| `in` | 들어 있는지 확인 |
| `not in` | 들어 있지 않은지 확인 |

 #### Example

```
fruits = ["사과", "바나나", "포도"]

print("사과" in fruits)       # True
print("수박" in fruits)       # False

print("수박" not in fruits)   # True
print("사과" not in fruits)   # False
```

 ## ✔️ 조건문 사용 방법

 ### if문

 조건이 맞을 때 코드를 실행.

```
age = 20

if age >= 18:
    print("성인입니다.")
```

 #### 결과

```
성인입니다.
```

---

 ### if \~ else문

 조건이 맞으면 `if`를 실행하고,\
 조건이 맞지 않으면 `else`를 실행

```
age = 15

if age >= 18:
    print("성인입니다.")
else:
    print("미성년자입니다.")
```

 #### 결과

```
미성년자입니다.
```

---

 ### if \~ elif \~ else문

 조건이 여러 개일 때 사용

```
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

 #### 결과

```
B
```

 ## ✔️ 반복문 사용 방법

 ### for문

 리스트에 있는 값을 하나씩 꺼내면서 반복할 때 사용.

```
fruits = ["사과", "바나나", "포도"]

for fruit in fruits:
    print(fruit)
```

 #### 결과

```
사과
바나나
포도
```

---

 ### for문 + range()

 `range()`를 사용하면 숫자를 순서대로 만들 수 있음.

```
for i in range(5):
    print(i)
```

 #### 결과

```
0
1
2
3
4
```

 > `range(5)`는 `0`부터 `4`까지 만든다.
>
>  `5`는 포함되지 않는다.

---

 ### while문

 조건이 맞는 동안 계속 반복

```
count = 1

while count <= 3:
    print(count)
    count += 1
```

 #### 결과

```
1
2
3
```

---

 ### break문

 반복문을 바로 끝낼 때 사용

```
for i in range(5):
    if i == 3:
        break

    print(i)
```

 #### 결과

```
0
1
2
```

---

 ### continue문

 현재 반복만 건너뛰고 다음 반복으로 넘어감

```
for i in range(5):
    if i == 2:
        continue

    print(i)
```

 #### 결과

```
0
1
3
4
```

---

 ### 반복문 + 조건문 활용

```
questions = ["asyncio란?", "", "FastAPI란?"]
valid_questions = []

for question in questions:

    # 문자열 앞뒤의 공백 제거
    cleaned = question.strip()

    # 값이 비어 있으면 건너뛰기
    if not cleaned:
        continue

    # 값이 있으면 리스트에 추가
    valid_questions.append(cleaned)

print(valid_questions)
```

 #### 실행 결과

```
['asyncio란?', 'FastAPI란?']
```

 #### 사용한 기능

 | 코드 | 설명 |
| --- | --- |
| `strip()` | 문자열 앞뒤의 공백 제거 |
| `if not` | 값이 비어 있는지 확인 |
| `continue` | 현재 반복 건너뛰기 |
| `append()` | 리스트에 값 추가 |
